# Explorando el éxito musical en Spotify

Proyecto de análisis exploratorio de datos desarrollado utilizando Python, Pandas y técnicas de visualización de datos sobre un dataset real de Spotify.

El objetivo principal del proyecto es analizar diferentes características musicales y estudiar su relación con la popularidad de las canciones dentro de Spotify.

---

# Tecnologías utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

# Análisis realizado

Durante el proyecto se realizaron diferentes procesos de análisis exploratorio de datos:

- Exploración del dataset
- Análisis de valores nulos
- Resumen estadístico
- Visualización de datos
- Análisis de géneros musicales
- Análisis de popularidad
- Correlaciones entre variables
- Clasificación de canciones según popularidad

---

# Resultados principales

El análisis permitió identificar diferentes patrones relacionados con la popularidad musical dentro de Spotify.

Algunas variables como la danceability y la energía muestran cierta relación con la popularidad de las canciones. Además, algunos géneros musicales presentan niveles medios de popularidad superiores al resto.
